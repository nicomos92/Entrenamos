# 1. Introducción

EntrenaMos es una plataforma digital diseñada para simplificar el trabajo diario de entrenadores personales, preparadores físicos y pequeños centros de entrenamiento.

El objetivo principal es reducir el tiempo que los profesionales dedican a tareas administrativas para que puedan enfocarse en lo más importante: acompañar el progreso de sus alumnos.

Este documento define la visión del producto y servirá como referencia para todas las decisiones relacionadas con diseño, desarrollo y evolución de la plataforma.

---

# 2. Problema

Actualmente muchos entrenadores administran su trabajo utilizando una combinación de herramientas:

- WhatsApp
- Excel
- Google Sheets
- Documentos PDF
- Notas del teléfono
- Calendarios
- Aplicaciones diferentes para rutinas

Esto provoca:

- Información dispersa.
- Mucho tiempo administrativo.
- Dificultad para realizar seguimiento.
- Mala experiencia para los alumnos.
- Escasa profesionalización del servicio.

EntrenaMos nace para resolver ese problema.

---

# 3. Visión

Queremos construir la plataforma de entrenamiento más simple, organizada y profesional para entrenadores de habla hispana.

No buscamos crear una aplicación con cientos de funciones.

Buscamos construir una herramienta que los entrenadores quieran utilizar todos los días.

---

# 4. Misión

Ayudar a entrenadores y alumnos a organizar el entrenamiento mediante una plataforma moderna, intuitiva y escalable.

---

# 5. Objetivos del Producto

## Corto Plazo

Construir un MVP funcional que permita a un entrenador administrar sus alumnos y compartir rutinas de entrenamiento.

Validar el producto mediante una beta cerrada con usuarios reales.

---

## Mediano Plazo

Agregar funcionalidades que aumenten el valor del producto:

- Seguimiento de progreso.
- Agenda.
- Estadísticas.
- Fotografías.
- Notificaciones.
- Plantillas.

---

## Largo Plazo

Convertir EntrenaMos en una plataforma integral para entrenadores y centros deportivos.

Incorporando:

- Nutrición.
- Inteligencia Artificial.
- Gestión comercial.
- Marca Blanca.
- Aplicación móvil.
- Panel Web.
- Integraciones.

---

# 6. Público Objetivo

## Cliente

Entrenadores personales.

Preparadores físicos.

Profesores.

Centros deportivos pequeños.

---

## Usuario Final

Alumnos.

---

# 7. Filosofía del Producto

La tecnología debe ayudar al entrenador.

Nunca reemplazar su conocimiento.

EntrenaMos organiza el trabajo.

Las decisiones siguen siendo del profesional.

---

# 8. Propuesta de Valor

EntrenaMos permite al entrenador:

- Centralizar toda la información.
- Crear rutinas rápidamente.
- Administrar alumnos.
- Organizar turnos.
- Compartir entrenamientos.
- Ahorrar tiempo.
- Brindar una experiencia profesional.

---

# 9. Principios del Producto

Toda funcionalidad nueva debe cumplir al menos uno de estos principios.

## Simplicidad

Debe ser fácil de utilizar.

---

## Rapidez

Debe reducir el tiempo administrativo.

---

## Organización

Toda la información debe encontrarse fácilmente.

---

## Escalabilidad

La arquitectura debe permitir agregar nuevas funcionalidades sin reescribir el sistema.

---

## Experiencia

El usuario debe disfrutar utilizar la plataforma.

---

# 10. MVP

La primera versión tendrá únicamente las funcionalidades necesarias para validar el producto.

## Profesor

- Login
- Dashboard
- Gestión de alumnos
- Gestión de ejercicios
- Gestión de rutinas
- Asignación de rutinas
- Agenda de turnos

## Alumno

- Login
- Visualización de rutina
- Registro de entrenamiento
- Perfil

---

# 11. Funcionalidades fuera del MVP

Estas funcionalidades quedan planificadas para versiones futuras.

- Nutrición
- Chat
- IA
- Estadísticas avanzadas
- Wearables
- Pagos
- Marca Blanca
- Marketplace
- Corrección mediante video
- Evaluaciones físicas

---

# 12. Roadmap

## MVP Beta

Validar el producto con un entrenador real.

---

## Versión 1.0

Lanzamiento público.

---

## Versión 2.0

Escalabilidad para múltiples entrenadores.

---

## Versión 3.0

IA y automatizaciones.

---

## Versión Enterprise

Centros deportivos y gimnasios.

---

# 13. Métricas de Éxito

El MVP será exitoso si:

- El entrenador administra todos sus alumnos desde EntrenaMos.
- Reduce el uso de Excel y WhatsApp.
- Puede crear una rutina en menos tiempo.
- Los alumnos utilizan la plataforma semanalmente.
- El entrenador desea continuar utilizándola luego de la beta.

---

# 14. Tecnología

El MVP será construido utilizando una arquitectura preparada para escalar.

Frontend:

- React
- TypeScript
- Vite

UI:

- Tailwind CSS
- shadcn/ui

Estado:

- Redux Toolkit

Backend (etapa posterior):

- Firebase

Arquitectura:

- Feature First
- Clean Code
- Componentes reutilizables

---

# 15. Concepto Rector

> "EntrenaMos ayuda al entrenador a organizar su trabajo para dedicar más tiempo a entrenar personas."

Toda decisión de producto deberá alinearse con este principio.

---

# 16. Futuro

EntrenaMos no será solamente una aplicación de rutinas.

Será una plataforma que acompañe el crecimiento profesional del entrenador.

El desarrollo será incremental.

Cada versión deberá aportar valor sin perder la simplicidad que caracteriza al producto.

---
